# Pravidh Audit Dashboard

Local-first Linux security/compliance dashboard for the `oscap-auto` project.

## Scope

- Ubuntu, Debian and RHEL-family Linux hosts
- Security score and fleet posture
- CIS / ISO 27001 / NIST readiness views
- Findings and remediation workflow
- Scan history
- AI-assisted remediation UX
- No cloud dependency in the dashboard UI

## Preview

Open `dashboard/index.html` directly in a browser. The current UI uses static demonstration data; the next implementation step is to connect it to the existing Python/OpenSCAP scanner output.
